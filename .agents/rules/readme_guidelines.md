# README Documentation Guidelines

## 1. 핵심 원칙
- **단순 레이아웃 및 디자인 변경 제외**:
  - 버튼 위치 이동, 여백 조정, 라벨 문구 수정, 내부 빌드 스크립트 등 단순 UI/내부 변경 사항은 README에 기재하지 않는다.
  - 이러한 변경 사항은 필요한 경우 `CHANGELOG.md`나 커밋 메시지에서만 다룬다.

## 2. 기능(Features) 중심 기술
- 사용자가 실제로 사용하는 핵심 기능(Features)만을 명시한다.
- 각 기능의 명칭과 핵심 역할이 직관적으로 드러나도록 작성한다.

## 3. 극도의 간결성 유지
- 장황하거나 장식적인 수식어를 일절 배제한다.
- 불필요하게 긴 문장 대신, 핵심 요점만을 담은 간결한 한 줄 글머리 기호(Bullet points)로만 표현한다.
